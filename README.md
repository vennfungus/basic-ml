# How I learn Machine Learning
In this repository, I shall summarise and synthesise of knowledge regarding fundamental ML models. The goals is firstly systematise my own knowledge and create a comprehensive summary of the fundamental components of basic ML, primarily. 

Thought it could serve the needs of the community in their own pursuit of learning.

## Folder Construct
```text
├── README.md
├── requirements.txt
├── .gitignore
├── regression.ipynb
├── classification.ipynb
└── src
    ├── regression.py
    ├── logistic.py
    ├── naivebayes.py
    └── metric.py
```

The construction is divided into two part. The `.ipynb` file, which perform algorithm with data, would be used as a visual vehicle. While the source code of `.py` is mainly used to describe the algorithm.

Beside, the algorithm will also be briefly described in terms of concept and input-output values, which insures who do not have basic understand about coding can also understand.
